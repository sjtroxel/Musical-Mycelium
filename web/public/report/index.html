How Musical Mycelium is evaluated

Every number on this page is generated from files committed to the repository, by the same code the evaluation suite runs with. None of it is typed by hand, and the build fails if the page falls out of date.

Grounded means traceable to a checkable source, not true. The gates below prove the first. Nothing on this page claims the second.

The sealed held-out set

Ten cases drawn from the corpus by a seed only the author holds, sealed, and never read during development.

9 of 10 correct, run 2 times in total, on 2026-09-19 02:12 UTC at artifact 0.10.0. The corpus is now 0.10.0.

One run of ten cases, 2 of them refusals, so one flip moves refusal accuracy by 50 points. It is an observation, not a rate, and it cannot be re-run for an error bar without spending the property the set exists to have.

What did not work

  • adv_025 fails the same way in every run. Its cause is not yet recorded here. Excluded from refusal_accuracy with its cause recorded, and still in the dataset and still scored.
  • adv_026 fails the same way in every run. Its cause is not yet recorded here. Excluded from refusal_accuracy with its cause recorded, and still in the dataset and still scored.
  • 10 cases changed verdict between identical runs: gold_v0_1_006, gold_v0_1_015, gold_v0_1_020, gold_v0_1_024, gold_v0_1_026, gold_v0_1_044, adv_006, adv_008, adv_009, adv_011. Five runs is the floor for that reason: three would have recorded a coin flip as a defect.
  • injection_resistance is not tested by the free run: no case planted a forbidden triple, so resistance was never tested. It is reported as not applicable, never as a pass.
  • traversal_recall is not tested by the free run: script-determined on this run -- the trace policy walked the path, not a model. It is reported as not applicable, never as a pass.
  • A failure no metric here can catch. Joy Orbison and Roy Orbison are one edit apart and both are in the corpus. A model that typed one for the other would resolve cleanly, cite correctly, and answer about the wrong person at 100% groundedness. The adversarial case that asserts one's influences about the other (adv_019) is refused, but only because that premise is false. The substitution itself is invisible.
  • 2,227 of 2,309 influence edges have one source. A second source speaks on 82, and 2 pairs are contested. Everywhere else the page can say how strongly one source was checked, not whether another agrees.
