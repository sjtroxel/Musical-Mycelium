Musical Mycelium

A goal-directed research agent that maps the history of music.

The hosting spine is live. The interface is not built yet, so there is nothing here to click for now.

The agent behind it is already running. It plans a traversal across a provenance graph built from Wikidata, passes every proposed edge through a deterministic gate, and generates prose only from the claims that gate approved.

Grounded here means every edge traces to a checkable source. It does not mean the edge is true.
